Every parameter of the flight solver, and what happens when you move it

The panel below is generated from a declared schema, not hand-written, so no input of the simulator can be left out of it. Each row carries its provenance kind and its source, and a parameter moved off the value its source supports says so in words. The sweeps run the real solver: sweep.js fetches index.html and lifts its own integrator functions out of it by name, so there is no second copy of the equations here to drift from the first.

Scope. A sweep moves parameters off the values params.json sources, so no point in a sweep except the committed one is a pre-registered test (see PREREG.md, RUNS.md). The comparison targets on the simulator page are second-hand field figures. The Lean verdicts shown here come from /api/lean/ through lean-client.js and evaluate the same formulas in floating point: they are not kernel checks. The physiology chain is off in a sweep, as it is in the page's default run. No bird data anywhere (class Aves is the frozen holdout). This page never writes to index.html.
