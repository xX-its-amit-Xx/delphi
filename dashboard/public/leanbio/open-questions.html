Open Questions

A law set says what this project holds proved. This page says what it holds unsettled — and what it tried and could not establish.

An open question carries one arm per live position, each arm's evidence quoted from its primary source. The split across arms is computed by the project's belief formula, not asserted. No arm of an open question is in any law set, and the registry guard refuses to accept a law that asserts one.

Failed theorems

Statements we tried and could not establish, kept with the reason so nobody reproposes them. Each says what survives the failure — a failure record that says only “it failed” throws away the result. Read the badge: some of these were never attempted (the single Lean build lock was contended, or they were abandoned on cost), and those say nothing about whether the statement is true.

Not checkable in principle

Sound statements — usually proved — with no falsifiable direction over any design. These are not waiting for data and they are not wrong: no input would make them bind, so each says what a forced check would wrongly flag.

Needs more inputs

Sound statements that nothing can currently check: the proof is fine, but no design property can be fed to it. Not failures — each lists the inputs that would make it bind.
