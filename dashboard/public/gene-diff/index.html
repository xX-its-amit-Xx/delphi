The diff, from one residue outward

A design, its base genome and the orthologue of its closest functional analogue, aligned residue by residue, then expanded through every scale this repository holds: expression, protein, modification, pathway, interactome and developmental time. Nothing on this page was derived here. Every value names the file it came from, and every gap is stated in place rather than left blank, because a blank column in an alignment reads as identity.

Class Aves is this project's frozen holdout. No bird sequence, annotation or orthologue is read by the build or shown here. Built by dashboard/public/gene-diff/build.mjs from sequences/, genotype/, omics/ and sim-engine/validate/; none of those are written by it.
